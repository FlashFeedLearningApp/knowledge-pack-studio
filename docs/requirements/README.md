# Requirements snapshot

This directory is a self-contained snapshot of the product and engineering requirements that
govern Knowledge Pack Studio. The seven copied files are byte-for-byte identical to the source
documents in the FlashFeed knowledge-packs repository at the time this project was scaffolded.

- Upstream repository: <https://github.com/FlashFeedLearningApp/knowledge-packs>
- Upstream definition folder: <https://github.com/FlashFeedLearningApp/knowledge-packs/tree/main/pipeline-definition>
- Main requirement: [`AUTOMATED_PIPELINE_REQUIREMENTS.md`](AUTOMATED_PIPELINE_REQUIREMENTS.md)
- Supporting authoring references: [`references/`](references/)

The implementation may initially cover only a milestone subset of the requirement. Gaps must be
listed in [`../ARCHITECTURE.md`](../ARCHITECTURE.md), not silently treated as complete.
